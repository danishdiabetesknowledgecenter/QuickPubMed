# Eksterne API-specifikationer (reference)

Denne mappe indeholder OpenAPI-specifikationer (YAML/JSON) for de tredjeparts-API'er, Mugin Scholar integrerer med. Spec'er hentet direkte fra udbyderen skal **ikke redigeres manuelt** — erstat filen med en ny download, hvis API'et ændrer sig. Altmetric og Dimensions udgiver ikke OpenAPI; de filer er rekonstrueret fra deres officielle badge-/API-docs.

Formålet er at have en versioneret, søgbar kopi af den kontrakt, vores egen kode (`backend/api/*.php`) implementerer imod — så man hurtigt kan slå et felt/parameter op uden at skulle ud på nettet, og så fremtidige migreringer (som Elicit v1→v2) har et konkret sammenligningsgrundlag.

## Filer

- `elicit-openapi.yaml` / `elicit-openapi.json` — Elicit API v2 (`https://elicit.com/api/v2`), hentet fra [docs.elicit.com/openapi.json](https://docs.elicit.com/openapi.json). Samme spec i to formater; YAML er konverteret fra JSON, fordi Elicit kun udgiver JSON. Bruges af `backend/api/ElicitSearch.php` og `backend/app/public-search-lib.php` (`muginPublicSearchFetchElicitSourceResult`).
- `openalex-openapi.json` — OpenAlex API (`https://api.openalex.org`, 44 paths, primært `/works` relevant for os). Hentet fra [developers.openalex.org/api-reference/openapi.json](https://developers.openalex.org/api-reference/openapi.json). Bruges af `backend/api/OpenAlexSearch.php` og `backend/api/OpenAlexWorkLookup.php`.
- `semanticscholar-openapi.json` — Semantic Scholar "Academic Graph API" (Swagger 2.0, ikke OpenAPI 3; `basePath: /graph/v1`). Hentet fra [api.semanticscholar.org/graph/v1/swagger.json](https://api.semanticscholar.org/graph/v1/swagger.json). Vi bruger `/paper/search` (relevans-rangeret, batch-hentet i sider af 100, cap 1.000 resultater totalt) — **ikke** `/paper/search/bulk`, som ikke er relevans-rangeret og derfor ville skade det RRF-baserede rerank. Bruges af `backend/api/SemanticScholarSearch.php` og `backend/app/public-search-lib.php` (`muginPublicSearchFetchSemanticScholarSourceResult`).
- `requesty-openapi.json` — Requesty Inference API (`https://router.requesty.ai`; EU: `https://router.eu.requesty.ai`, som ikke står i spec'en). Hentet fra [docs.requesty.ai/api-reference/requesty_inference-openapi.json](https://docs.requesty.ai/api-reference/requesty_inference-openapi.json). Vi bruger `POST /v1/responses`. Management-API'et (`api-v2.requesty.ai`) indgår ikke. Bruges når `MUGIN_LLM_PROVIDER=requesty` via `backend/app/helpers.php` (`muginGetLlmApiUrl` m.fl.).
- `altmetric-openapi.json` — Altmetric badges + Details Page API v1 (`https://api.altmetric.com`). Ingen officiel OpenAPI; rekonstrueret fra [docs.altmetric.com/badges](https://docs.altmetric.com/badges/getting-started/) og [Details Page API](https://docs.altmetric.com/details-page-api/getting-started/). Vi indlejrer donuts i browseren (`src/components/ResultEntry.vue`); PHP kalder ikke API'et. Embed-scriptet slår op på `GET /v1/doi/{doi}` og `GET /v1/pmid/{pmid}`.
- `dimensions-openapi.json` — Dimensions badges + Metrics API (`https://metrics-api.dimensions.ai`). Ingen officiel OpenAPI; rekonstrueret fra [badge.dimensions.ai](https://badge.dimensions.ai/). Vi indlejrer citation-badges i browseren (`src/components/ResultEntry.vue`); PHP kalder ikke API'et. Badge-scriptet slår op på `GET /doi/{doi}` og `GET /pmid/{pmid}`. Dimensions Analytics/DSL (`docs.dimensions.ai/dsl`) indgår ikke.

Dette er **ikke** det samme som `backend/docs/public-search-openapi.yaml`, som er Mugin Scholar's *egen* offentlige API-kontrakt (den, eksterne klienter integrerer imod), ikke en reference til en tredjeparts-API.
